# Créditos dos modelos de ata

Os modelos `reuniao`, `daily`, `projeto`, `retrospectiva` e `cliente` são baseados nos
modelos de resumo do **Meetily** (<https://github.com/Zackriya-Solutions/meetily>),
© 2024 Zackriya Solutions, licença MIT. A estrutura (seções, instruções e formato das
tabelas) vem de lá; o texto foi traduzido para o português e adaptado.
A licença original está em `LICENSE-meetily.md`.

O modelo `aula` foi escrito para o Escuta.

Para criar o seu: copie um `.json` desta pasta, mude o nome do arquivo e o conteúdo,
e reinicie o servidor. O nome do arquivo (sem `.json`) é o identificador.
